**What shipped**
- A frozen Resolution Record adapter (`src/components/historical-week/record-review.ts`) feeds #169's shared six-section renderer from the immutable record only. A record from the real Confirmation path produces the same sections, chips, order, outcomes, exceptions, adjustments and Result as the live review of that week.
- Record-local names only; characters are shown as "Character N". Event labels are derived from the record's own tree.
- Legacy compatibility: older formats, missing source snapshots ("Not recorded"), dice arrays and totals, actor-bearing transfers, recorded costs and the old buyoff warning.
- An import test keeps the adapter away from the store, Convex, React and the rules code.
