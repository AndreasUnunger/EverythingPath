**What shipped**
- Additive preparation of the blank event positions the rules call for, with stable identities scoped to the draft, so two devices converge on the same tree. No child edit is sent before its occurrence has been accepted, retries are bounded and then offer Retry, and a replaced candidate choice never gets stale candidates. It follows the current candidate rules; the Roll Twice rule change and Ruleset Version bump are #191.
- A shared rules-text catalogue, `src/lib/event-rules-text.ts`, covering all 24 event types and their Twice clauses, with a test that keeps it in step with the rules corpus. The Roll Twice and Cache Discovered clauses use `militia-verbatim.md`. #164, #165, #192 and #193 use this catalogue (see [the ownership note on #143](https://github.com/AndreasUnunger/EverythingPath/issues/143#issuecomment-5856384681)).
- Stable hierarchical event labels (Event 1, 1.1, 2A/2B, 2A.1…), so rolling Roll Twice never renumbers other events, applied across Activity, Persistent and Summary.
- The separate "Remove extra Event N" control is removed, after a read-only production check found no legacy extra positions. The #143 §5 route of repairing by clearing remains.
