Shared Action Slot Oracle

This throwaway prototype asks: what must two players observe for a slot to be claimed, staged, confirmed, released, or expired without tests depending on arbitrary timing?

Future-feature oracle: this models only the player-visible outcomes to require when the product introduces first-claim locking. The current mandatory suite instead tests supported staging and confirmation propagation without competing writes. GM correction is omitted because GM-only controls do not yet exist.
