# Don't copy from the summary prototype: #146 Finished weeks (summary-prototype aspects only)

Scope: only what Finished weeks takes from `/prototype/summary?variant=B` (`65d472d`), namely the six-section record body. The page, list and audit layout come from the finished-weeks prototype and are covered elsewhere. Spec: [#146](https://github.com/AndreasUnunger/EverythingPath/issues/146), with the frozen-record contract in [#145 §5](https://github.com/AndreasUnunger/EverythingPath/issues/145). Decisions: [#117 approval](https://github.com/AndreasUnunger/EverythingPath/issues/117#issuecomment-5845007868) and [amendment](https://github.com/AndreasUnunger/EverythingPath/issues/117#issuecomment-5845032926).

- **Live wording.** The prototype uses the live labels "Now", "Result · week 15 begins" and "No Table Adjustments. The Final preview equals the Rules Baseline." History uses **At confirmation**, **Result · week N+1 began** and **No Table Adjustments. The Final outcome equals the Rules Baseline.** #146 §1 (Table Adjustments and Result bullets), #145 §5 "Both modes…".
- **Editing controls everywhere.** The prototype has inline reason inputs, × clear, ✎/🗑, ▲▼ reorder, the four kind cards, **Remove obsolete exception** and forms. History shows exceptions, reasons and outcomes as quoted read-only text, with none of these controls. #146 §1 Table Adjustments bullet, SUM-07/SUM-08 rows in §4.
- **Live frame chrome around the sections.** The prototype shows the Review the week block (Required decisions, Go links, Confirm), the stepper, the "Militia · now → after" side panel, the "← Persistent" footer and the "Changes saved" status. None of these belong in history. The header and footer there are the record header and the merged read-only line. #146 §1 header and footer bullets.
- **Live warning handling.** The prototype lists warnings only in the top block and hides them when rulings are toggled off. History places each recorded warning under its item or phase through the shared contract. It keeps the historical differing-buyoff-cost warning that live Summary filters out. #146 §5 "Frozen-record presentation…" (Persistent paragraph), #145 §5 frozen adapter paragraph.
- **Hardcoded Show all context.** The prototype prints a literal roster/officer string and `final.queued`. History reads recorded Operating from, uneventful-week carry, first-Upkeep skip, officers at confirmation and the successor context from the selected record, using record-local names only. #146 §1 Result bullet, §5 frozen presentation.
- **Complete mock data with no gaps.** Every prototype value exists; Now even shows a placeholder "carried". Old records can lack `sourceMilitiaSnapshot` and other facts. Show **Not recorded** or **Militia facts were not included in this record**; never show zero or unchanged. #146 §5 compatibility paragraph, §8.
- **Hardcoded phase chips and integer-gp strings.** `phaseDelta` is constant, and treasury prints as "1245 gp" from mock whole numbers. History phase chips show recorded net changes, excluding Table Adjustments. Treasury uses copper-exact gp formatting. #146 §1 Detail and Result bullets, §5 "Phase totals exclude subsequent Table Adjustments".
- **Colour-only Final emphasis.** The prototype marks a Final difference only with `text-sky-300`. History also states the difference in text. #146 §1 Result bullet, §8 accessibility.
