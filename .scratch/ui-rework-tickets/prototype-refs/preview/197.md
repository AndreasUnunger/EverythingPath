## What to build

Finished weeks and Campaign home can list every recorded week with truthful effective-record metadata and dates from one bounded, authorized query, without changing any stored record or the current history view.

Split from [T36 / #184: Browse finished weeks and page dated audit entries](https://github.com/AndreasUnunger/EverythingPath/issues/184), which keeps the index and audit UI.

This is a bounded backend contract exception to vertical UI slicing. It must remain independently verifiable and green; the existing history browser keeps working unchanged.

## Acceptance criteria

- [ ] Add `canonicalHistory.list` exactly per the approved signature and `{ weeks, earlierWeek, selected }` result, using bounded indexed distinct-week seeks that skip whole correction chains, exact-week `selectedWeek` metadata and no unbounded collect, count scan or new table/index. Prove `{ campaignId, limit: 3 }` returns the three greatest weeks latest-first for Campaign home.
- [ ] Project at most two record-local headline facts from the effective record’s stored before/final facts, with supported legacy extraction and an empty list when nothing is comparable; return no raw artifacts and call no rules resolver or current labels.
- [ ] Add only top-level selected and per-audit-row `createdAt` from document `_creationTime` to `canonicalHistory.read`, keeping schemas, immutable artifacts and existing arguments/results unchanged. Both queries derive identity server-side, enforce membership and campaign/militia/week/record scope directly and reject malformed selectors.
- [ ] Include the slice’s applicable tablet, phone and desktop behavior, accessibility, structural validation, membership/campaign isolation, multi-device save/failure/reload and Confirmation safeguards; retain working existing controls for unsplit capabilities. No prototype merge or unapproved contract change.
- [ ] Run `pnpm -s typecheck`, `pnpm -s lint` and relevant meaningful unit/integration/browser scenarios from the owning spec. Record actual results and environment limits; update capability inventory locations and evidence only for shipped work.
