## Unchained Classes

Decided by [Decide which Pathfinder Unchained rules the builder supports](https://github.com/AndreasUnunger/EverythingPath/issues/226).

- **Scope.** The four Unchained Classes (barbarian, monk, rogue, summoner), their archetypes, and _Pathfinder Unchained_'s other catalog content are in. Signature Skill and skill unlocks, the stamina feats, Combat Trick feats and scaling items are plain prose catalog content: nothing is derived from them, and no stamina pool exists. Every alternate rule system in the book is out of scope, so there are no variant rule switches on a campaign or a Character.
- **Class entries.** Each Unchained Class is its own `class` Catalog Entry, imported from Foundry's `<Class> (Unchained)` records, with `counterpartOf` pointing at the original class. Its features are found through the class's links, not by the PZO1131 source, which most unchained feature records lack.
- **One version per Character.** Class Levels in both an original class and its Unchained Class show an advisory warning ("individual characters must use one version or the other exclusively").
- **A version of the same class.** The book's own framing, applied consistently:
  - Levels of an Unchained Class count as levels of the original wherever something counts levels in that class: `@classLevel.<classKey>`, requirements, and the favored class with its favored class options. If both versions are recorded despite the advisory warning, each recorded Class Level contributes once to the shared family count.
  - A prerequisite naming a class feature is met by the same-named feature of either version, ignoring Foundry's `(UC)` suffix: Extra Rage accepts _Rage (UC)_. See "Rules checks".
- **Archetypes.**
  - An archetype for the original barbarian, rogue or summoner applies to the Unchained Class ("as long as the classes still have the appropriate class features to replace"). Its `replaces` rows match the Unchained Class's `featuresByLevel` by feature name and class level, ignoring `(UC)`. A row with no match shows an advisory warning and replaces nothing.
  - An archetype for the original monk on the unchained monk shows an advisory warning ("with the exception of the monk").
  - Archetypes written for an Unchained Class name it directly. One whose source names both versions lists both in `classEntryIds`.
  - The Pathfinder Society restrictions (no barbarian archetype that changes rage, no summoner archetype that changes the eidolon's base form) are campaign policy, not rules text, and are not adopted.
- **Eidolons.** Unchained summoner levels support only the Unchained eidolon, and original levels only the original eidolon; a mismatch leaves the eidolon unresolved without deleting choices (#418, see "Companions").
- **Spells.** The unchained summoner's revised spell list is ordinary per-class spell data under its own class tag, and its casting table is the bard's (see "Spellcasting").

**Prepared class controls (#406).** `useCharacterSheet.classes` exposes the available class definitions, Prestige Class entry previews, original/Unchained version choices and compatibility warnings. The next-level picker evaluates entry against the recorded prefix before the first Prestige Class level; an existing class retains its original entry position, separately from qualification in the current build. A row-edit preview checks the proposed class at that row's recorded position. Unmodeled requirements stay readable prose and unresolved calculations never become a failed prerequisite. The scoped `characterSheet.switchClassVersion` writer changes the whole class family in one operation while retaining Class Level identities, HP, order and recorded choices; matching Grant/prompt state follows existing restoration rules and unmatched state remains dormant. Save/refusal and another-player feedback belong beside the class control. Mixed versions, unmatched Archetype replacements and original-Monk compatibility remain independently acceptable warnings. The switch also maps an Attack Routine's recorded flurry of blows to the target version's (#414); each flurry counts only its own version's monk levels. Since #583 the same writer also switches to another Catalog Copy of the class, to exactly the chosen definition, and links to the earlier copies follow it (see "Class Levels and Hit Dice"). One "Rules used" control on the class's first level offers both kinds of choice and replaces the separate version control. Choosing the version a level already has unifies levels recorded with the other version, as before.

The isolated prepared catalog includes representative Duelist, Shadowdancer and Mystic Theurge prestige tables (Mystic Theurge since #415, with its casting advances) and four distinct Unchained class definitions with source-backed schedules. This is representative seed content, not complete catalog curation or production activation. Shadowdancer's exact Perform (dance) requirement is typed and remains unresolved because the current skill model records only generic Perform; generic Perform ranks do not substitute for a specialization. Full skill specializations and remaining catalog curation retain their own work scope.
