# Exact Weekly Confirmation

Issue [#80](https://github.com/AndreasUnunger/EverythingPath/issues/80) extends the shared persistence seam with accepted preview and whole-week Confirmation. The canonical Convex endpoints remain limited to the configured, owned isolated preview campaign. Live campaign cutover and the Workspace presentation are separate tickets.

`createDraftPersistence.preview()` reads the authoritative adapter preview only when no local edits are pending. It checks the accepted draft identity and revision, retains a private copy, and returns the complete baseline and final outcome with readiness and warnings. A browser projection cannot supply the retained accepted review, and caller changes to returned nested values cannot change that review.

`confirm(review)` immediately pauses new local edits, waits for earlier submissions, and sends precisely the retained reviewed source. It never replaces that source with the just-flushed revision. Each attempt consumes the retained review. Failure refreshes accepted draft state and requires another preview and explicit attempt. Temporary transport failures retry the same operation identity; rejected requests are not retried. Pending forecasts cannot become accepted reviews while their edits remain pending.

Both adapters recompute the complete shared Rules Projection from authoritative source. The request binds draft identity, draft revision, full canonical source key, external source revision, and ruleset version. A relevant external change invalidates the request even when the numerical outcome is unchanged. Incomplete or invalid referenced facts fail before any state is applied.

The Convex mutation applies the entire final snapshot, appends an immutable Resolution Record containing the complete source, ruleset, baseline and final plans, adjudication, warnings and outcome, closes the old draft, and creates one empty successor with the projected fixed context. These writes share one transaction. The successor has fresh identity, revision zero, empty choices and decisions, and the next week/day context. A record identity derived from the stable confirmation operation supports retry deduplication. Competing operations cannot advance a closed draft; delayed edits cannot target its successor. Existing append-only record supersession remains reserved for historical correction and never reopens a closed draft.

Closing removes the draft and its initial editable snapshot immediately. Bounded scheduled cleanup removes accepted base snapshots and target rows; closed status prevents these historical payloads from authorizing any new edit while cleanup runs. Minimal operation requests and receipts remain for exact retry deduplication. The cleanup processes four potentially large snapshots and 32 small target rows per transaction.

`runConfirmationContract` runs eight scenarios against the deterministic memory authority and real authenticated Convex clients in the required persistence browser project. They cover complete stored outcomes, simultaneous confirmations, external source changes, incomplete input, the submission barrier, rollback, lost acknowledgements, and edit/Confirmation races. The rollback fixture reserves a successor identity so the real final write fails after the snapshot, record, and closure writes; inspection verifies the whole transaction rolled back. The fixture controls are internal and require the declared owned preview scope.

Additional integration tests verify invalid source references, authorization, cleanup across multiple batches, and retained retry receipts. Independent QA checks a literal Special action costing 20 copper followed by a seven-copper Table Adjustment: a 100-copper source records an 80-copper baseline and commits 87 copper, with the remaining state and next-week context explicitly asserted. No numerical expected value is derived from the returned plan.

The final isolated gate `MERJak` passed all seven required Playwright tests on first attempts, including authentication, all five supported tablet journeys, ten editing scenarios and eight Confirmation scenarios. The actual contract ran for 224.8 seconds and also verified ready-preview outsider, anonymous and cross-campaign refusals plus ordinary-player Confirmation. Independent QA's barrier, source-provenance, rollback, immutable-history and mutable-preview regression probes passed. An earlier run, `A0OhAh`, stopped during isolated deployment before tests; a fresh deployment succeeded without a source correction, and its original cause was not established.

The full local suite passed 851 tests across 84 files. Typecheck and lint pass. The updated rules catalog reports 372 covered cases, 293 explicit remaining gaps and zero errors; subsequent Workspace, UI and cutover work remains explicit.
